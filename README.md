# 🏃 JustLeave (PWA)

> **「開いて0.1秒で出発判断」徒歩時間を逆算する出発カウントダウンタイマーPWA**

乗換案内アプリのように毎回駅名を入力・検索する手間を排除し、オフィスや自宅から駅ホームまでの徒歩時間を考慮して「今乗るべき電車」と「今すぐ出るべきリミット時刻」を0秒で即断できる通勤・出発専用PWAです。

現在は **木場駅（東西線 西船橋・東葉勝田台方面）の快速特化** を第一弾として実装。今後、中野方面や自宅最寄り駅、他路線へのマルチ駅展開を予定しています。

---

## 🌟 特徴

1. **入力ゼロ・起動0.1秒（ローカルファースト）**
   - 画面を開いた瞬間に、現在時刻から「次の快速・急行」と「出発リミット（徒歩◯分前）」を特大表示。
   - `localStorage` キャッシュにより、電波が届きにくい地下やオフィスの奥でも0秒起動。
2. **オフィス出発リミット＆リアルタイム・カウントダウン**
   - 電車の発車時刻から徒歩時間（デフォルト10分）を引いた「オフィスを出るべきリミット時刻」を特大表示。
   - 秒単位のカウントダウン（あと◯分◯秒で出発）。
   - 「余裕あり（緑）」「準備（黄）」「今すぐ出発（橙）」「リミット経過（赤）」の直感的な状態通知。
3. **徒歩分数のワンタップ微調整**
   - 雨の日や荷物が多い日は「12分」、急ぎは「8分」など、ワンタップで即座に再計算・記憶。
4. **月次バックグラウンド自動更新**
   - 起動時に「月が変わったか」を自動判定し、バックグラウンドで最新の時刻表JSONをサイレント同期。
5. **PWA対応（ホーム画面追加）**
   - iPhone（Safariの「ホーム画面に追加」）やAndroidで、アドレスバーのない全画面ネイティブアプリ感覚で利用可能。

## 🚀 開発・起動

```bash
# 依存関係インストール
npm install

# 開発サーバー起動 (デフォルト: http://localhost:3340)
npm run dev

# プロダクションビルド
npm run build
```

## 🔄 時刻表データの更新

```bash
# 木場駅（西船橋方面）の最新時刻表を取得・JSON更新
python3 scripts/update_timetable.py
```
